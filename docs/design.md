# 設計書（Phase 0 で承認済み）

音楽理論・作曲学習アプリの設計の要点と、ユーザーと合意した決定事項の記録。

## 決定事項

| 項目 | 決定 |
|---|---|
| 開発場所 | `D:\music app`。GitHub にコピーを保管（Push は毎回ユーザーの許可を取る） |
| iPhone での利用 | GitHub Pages で公開（Phase 10。公開リポジトリ。公開作業は許可を取ってから） |
| ローマ数字 | 日本式（Ⅵm・Ⅳ△7）が標準。設定で英米式（vi・IVmaj7）に切り替え可 |
| オクターブ表記 | FL Studio式（中央のド = C5）が標準。設定で C4 式に切り替え可。**内部データは国際式（C4 = MIDI 60）で保存** |
| 拍子 | まず 4/4 のみ |
| ドラム | 再生用に実装し、MIDI の Track 4: Drums にも出力 |
| 五線譜 | シンプルな自作 SVG 表示 |
| 教材 | まず第1〜3章。Claude が執筆し、ユーザーが分かりやすさを確認 |
| 開発順 | 音声エンジンを学習機能より先に作る（下表） |
| ローカル Commit | 各 Phase 完了時に自動 |
| Phase の区切り | Phase 1 完了後のみ停止して確認。以降は自動で進める |

## 構成の原則

- `src/theory/` は React・音声に依存しない純粋な計算（自動テストで正確さを保証）
- `src/audio/` は全画面で共通の音声エンジン（1つだけ）
- 音は「文字＋変化記号＋オクターブ」で保持し、C# と D♭ を区別する
- 時間は tick（1拍 = 480）で管理
- データは端末内（IndexedDB）のみ。サーバー・ログイン・AI API・外部 CDN は使わない
- URL はハッシュ方式（`#/learn`）。GitHub Pages とオフラインで確実に動くため

## フォルダ

```
src/
  app/          起動・画面移動・レイアウト
  features/     機能ごとの画面（1機能 = 1フォルダ）
  components/   共通部品（鍵盤・五線譜・UI）
  theory/       音楽理論エンジン
  audio/        音声エンジン
  midi/         MIDI 出力
  storage/      IndexedDB・バックアップ
  content/      教材データ
  stores/       共有状態（設定など）
  types/        型定義
scripts/        補助スクリプト（アイコン生成）
docs/           設計書
```
