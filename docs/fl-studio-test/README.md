# FL Studio 21 での MIDI 読み込み確認の手順

このアプリで書き出した MIDI ファイルが FL Studio 21 で正しく使えるか、確認していただくための手順です。

## 確認用のファイル

このフォルダの **`FL Test - Komuro.mid`** は、アプリで実際に作って書き出したファイルです。

| 項目 | 内容 |
|---|---|
| テンポ | BPM 100・4/4拍子 |
| 長さ | 4小節（小室進行：Am → F → G → C、1小節ずつ） |
| Track 1：Chord | コード（3音ずつ、1小節の長さ） |
| Track 2：Melody | 1小節目に4分音符が4つ、2小節目の頭に1つ（C5 D5 E♭5 F5 E♭5 ※一般的な表記） |
| Track 3：Bass | ルートと5度を4分音符で交互（A → E → A → E …） |
| Track 4：Drums | 8ビート（キック・スネア・ハイハット）。チャンネル10（ドラム用） |

自分で作った作品を確かめたいときは、アプリの「作曲画面」または「保存した作品」の「⬇ MIDI」で書き出したファイルを使ってください。

## 手順

1. FL Studio 21 を起動し、新しいプロジェクトを作ります（File → New）。
2. メニューの **File → Import → MIDI file...** を選び、`FL Test - Komuro.mid` を開きます。
   （ファイルを FL Studio の画面にドラッグ＆ドロップしても読み込めます）
3. 読み込みの設定画面が出たら、最初は**何も変えずに**「Accept」（または OK）を押します。
4. 次の点を確認してください。

## 確認してほしいこと（チェックリスト）

- [ ] エラーが出ずに読み込めた
- [ ] チャンネルラック（Channel rack）に **Chord・Melody・Bass・Drums** の4つ（またはそれに近い名前）が並んだ
- [ ] テンポが **100**（または 100.000）になっている
- [ ] 各チャンネルのピアノロールを開くと、音符が**グリッド（マス目）にぴったり**並んでいる（ずれていない）
- [ ] Chord のピアノロールで、1小節ごとに3音の和音が4つ並んでいる
- [ ] Bass が1拍ごとに並んでいる
- [ ] Drums で、キック（FL Studio の表示で C3）・スネア（D3）・ハイハット（F#3）が分かれて並んでいる
- [ ] 再生すると、音が鳴る（鳴らない場合は下の「音が鳴らないとき」へ）

## 音が鳴らないとき

MIDI ファイルには「どの音を・いつ・どれくらいの強さで」の情報だけが入っていて、**音色そのものは入っていません**。
FL Studio の設定によっては、読み込んだチャンネルに音源が割り当てられず、音が出ないことがあります。
その場合は、各チャンネルに好きな音源（例：FL Keys・FLEX・3x Osc、ドラムは FPC など）を割り当ててください。

## 結果の伝え方

チェックリストの結果を、できたもの・できなかったものに分けて教えてください。
うまくいかなかった項目は、画面に出たメッセージや、どうなったか（例：「Drums が1つのチャンネルにまとまった」）を書いていただけると、原因を調べやすくなります。
